# EP Conexões & Negócios

Site institucional da EP Conexões & Negócios.

## Tecnologias

- Python 3.12+
- Flask
- HTML5
- CSS3
- JavaScript

## Estrutura

backend/
frontend/
static/
templates/
config/
routes/
services/

## Instalação

Criar ambiente virtual:

python -m venv .venv

Ativar no Windows:

.\.venv\Scripts\Activate.ps1

Instalar dependências:

pip install -r requirements.txt

## Executar

python app.py

O site estará disponível em:

http://127.0.0.1:5000

## Páginas

Home:

/

Trabalhe conosco:

/trabalhe-conosco

## Candidatura

O sistema de candidatura ainda não possui destino configurado.

Configure posteriormente através do arquivo .env.
